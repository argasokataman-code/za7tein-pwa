# SelectField — dropdown sendiri (ganti `<select>` peramban)

**File:** `src/components/ui/SelectField.tsx` · **CSS:** `src/styles/system/_forms.scss`
(`.field-select`, `.field-select-menu`, `.field-select-option`) · **Keputusan:** DEC-88101 ·
**Kendala:** BUG-102016.

## Kapan dipakai
Setiap field yang butuh memilih **satu nilai dari daftar pendek** (bank, jenis, kategori datar,
metode). **Jangan** pakai `<select>` bawaan peramban: tampilannya lepas dari design system.
Untuk daftar panjang / butuh ikon per opsi / filter, pola lain tetap berlaku (`BottomSheet` +
`.sheet-menu`, atau chip `.merchant-chip` untuk filter).

## Cara pakai
```tsx
import { Controller } from 'react-hook-form'
import { SelectField } from '../components/ui/SelectField'

<Controller
  name="bankName"
  control={control}
  render={({ field }) => (
    <SelectField
      label="Bank"
      options={BANK_OPTIONS}       // readonly string[]
      value={field.value}
      onChange={field.onChange}
      placeholder="Pilih bank"
      invalid={Boolean(errors.bankName)}
      describedBy={errors.bankName ? 'payout-bank-error' : undefined}
    />
  )}
/>
```
Props: `options`, `value`, `onChange`, `placeholder`, `label` (aria), `invalid`, `describedBy`.
Trigger memakai `.form-control` + `field-shape` (satu bentuk dengan input lain), jadi error
(`.error`/`aria-invalid`) dan focus ring ikut token yang sama.

## Kendala yang mengikat implementasi (jangan diubah tanpa alasan)
- Daftar dibuka **inline** (mengalir di bawah trigger) — **bukan** `BottomSheet` kedua.
  `BottomSheet` bertumpuk rusak: satu tap pilih opsi menutup **dua** panel sekaligus
  (`BUG-102016`), dan menu `position: absolute` terpotong `overflow: auto` panel form.
- Kalau kelak butuh daftar melayang, perbaiki `BottomSheet` (atau pakai portal non-modal),
  jangan menumpuk dua `BottomSheet`.

## Pemakai saat ini
`/merchant/payout-accounts` dan `/courier/payout-accounts` (pemilih bank) — sebelumnya `<select>`
bawaan. `PersonalData` (gender), filter `AdminLedger`, dan picker operator Super Admin
**belum** dipindah.
