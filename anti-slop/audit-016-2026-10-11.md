# Audit 016 — Layar auth (onboarding kurir) di desktop

**Tanggal:** 2026-10-11
**Pemicu:** `/courier/onboarding` "jelek sekali" di website (deployed `sa7tein-k.vercel.app`).
**Skill:** senior-fe (mode After → fix), dial `ENERGY 1 / RHYTHM 1 / MOTION 1`
(DNA.md: shell 430, satu mode, tanpa pengecualian kecuali `/superadmin/*`).

Semua temuan diverifikasi lewat DOM (bukan tangkapan layar), sesuai DNA §8.

---

## Temuan

### F-01 (HIGH) — Varian baris desktop memecah kolom 430 jadi form 162px
- Akar: `src/styles/system/_auth.scss` `@media (min-width:900px)` mengubah `.auth`
  jadi `flex-direction: row` (foto `flex: 1 1 50%`, panel `width: min(100%, 420px)`).
  Tapi `.app-shell`/`div[class*=-page]` (`app/part-01.scss:76-78`) mengunci kolom
  `--shell-max` 430px di lebar berapa pun, dan DNA.md:13/38 hanya mengizinkan
  `/superadmin/*` lebar.
- Akibat terukur @1440px: shell 430 → foto **268px** + panel form **162px**;
  input **~130px**. Label dan placeholder terjepit. Ini penyebab "jelek sekali".
- Tak ada keputusan docs untuk tata letak dua-panel; hanya komentar sumber.

### F-02 (MEDIUM) — Radio "Kendaraan" tanpa state terlihat
- `_auth.scss` menggambar state terpilih lewat `.auth-zone.is-on`, tapi
  `CourierOnboarding.tsx:92,96` merender `className="auth-zone"` polos, tanpa `is-on`,
  tanpa state React. Radio aslinya `opacity: 0`, jadi memilih Motor/Mobil **tidak
  mengubah apa pun** secara visual. (MerchantSignUp lolos karena mencerminkan nilai
  ke state; kurir tidak.)

### F-03 (MEDIUM) — Teks persetujuan tertutup kotak centang
- `.auth-consent` memasang `gap` untuk memisah kotak dan teks, tapi baik input aslinya
  maupun kotak `::before` digambar **absolut** di `left: 0`; `gap` tak pernah memberi
  ruang karena keduanya di luar alur. Teks mulai di x=0 → 20px pertama tertutup kotak
  ("Saya" terbaca "a"). Terukur span.x 205 == consent.x 205 sebelum perbaikan.

---

## Perbaikan (root, satu tempat: `_auth.scss`)

- **F-01** — buang ketiga blok `@media (min-width:900px)` (`.auth`, `.auth-photo`,
  `.auth-panel`). Auth mengikuti kontrak shell: kolom 430 di lebar berapa pun.
- **F-02** — perluas selector terpilih jadi `.auth-zone:has(input:checked)` (dan
  `::before`-nya). Setiap pemakai dapat state terlihat tanpa JS; `.is-on` tetap
  didukung untuk layar yang sudah mencerminkannya.
- **F-03** — `padding-left: calc(20px + var(--space-3))` pada `.auth-consent`;
  kotak tetap di `left: 0`, teks bergeser 32px.
