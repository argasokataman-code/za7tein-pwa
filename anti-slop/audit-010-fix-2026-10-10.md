## Perbaikan
- `useFood` mengembalikan `{ food, loading }`; dengan API hidup mock **tidak** dipakai —
  `loading` → status "Memuat menu…", id tak dikenal → "Menu tidak ditemukan" (kosong).
- `MenuDetail`: fallback `items[0]` dibuang; guard loading/not-found sebelum render.
- `/reviews` diganti keadaan kosong ("Belum ada ulasan."); tidak ada kartu contoh.
- `src/data/reviews.ts` + tipe `Review` dihapus; kelas state/empty pindah ke
  `src/styles/system/_menu-states.scss` (batas 600 baris).
- Copy dilokalkan; doc `FileStructureSection` tidak lagi menyebut `data/reviews.ts`.
