# Audit 012 — Beranda merchant (/merchant), mobile design

Tanggal: 2026-10-10
Mode: senior-fe **After** (audit). **Belum ada perubahan kode**; tunggu persetujuan nomor.
Cakupan: 1 halaman, `/merchant` (MerchantDashboard + MerchantHomeHero), kolom 430px, PWA app-mode.
Design Read: `<app screen>` untuk `<merchant pemilik warung>` dengan dial **ENERGY 1 / RHYTHM 1 / MOTION 1** (utility, tenang).

## Metode & bukti
- Pengukuran DOM di jendela e2e merchant (port 9361, build 4173): `getBoundingClientRect`,
  `getComputedStyle`, kontras dihitung komposit (warna teks vs latar nenek-moyang pertama yang solid).
- Target sentuh: semua `a`/`button`/`[role=button]` dengan sisi < 44px.
- Gate browser `/merchant --pwa --strict` **2/2 PASS** (shell 390/430, overflow 0, gulir bersarang 0).
- Vision (`gdescrib`) hanya dipakai sebagai sanity visual; klaim yang tak cocok DOM dibuang.

Catatan HG-02: temuan **#1** adalah konflik, bukan putusan. Repo sengaja menerima 4,02:1 untuk
`--on-brand` di permukaan oranye (tercatat di Changelog). senior-fe HG-05 menolaknya untuk teks normal.
Pilih: **pertahankan pengecualian** (tandai sebagai keputusan sadar) atau **perbaiki** (gelapkan latar
kartu, atau naikkan ukuran/bobot label & sub sampai ambang teks besar).

## Yang sudah benar (jangan diutak-atik)
- **Target sentuh semua ≥44px** (`smallTargets: []`) — HG-05 lolos untuk ukuran sasaran.
- **Tidak ada teks < 12px**; skala huruf halaman: 12 / 13,15 / 16 / 28,45px.
- **Tanpa em dash** di salinan halaman (`—` count = 0) — HG-11.
- Shell terkunci (390→390, 1440→430), gutter 20px, `overflow-x 0`, satu penggulung = dokumen.
- **Loading state ada**: `.merchant-skeleton` menahan seed sampai data API mendarat (audit 011 lanjutan).
- Heading kartu sudah `role="heading" aria-level=2` (menu terjual / komposisi / modal) selaras `H2` asli.
- Ikon Lucide, tanpa emoji, sparkline & donut punya `aria-label`.

## Catatan batas
- Kontras dihitung pada latar solid efektif; gradasi/opasitas dekorasi tak dihitung.
- Empty-state dinilai dari jalur render (belum direproduksi dengan data 0 order di layar).
- Peran admin/superadmin tak diaudit (di luar cakupan 1 halaman).

## Usul perbaikan (menunggu persetujuan nomor)
1. **#1** — perjelas konflik HG-02 dulu. Opsi a: gelapkan `--sa7tein-orange` sedikit sampai ≥4,5:1
   (memengaruhi seluruh merek). Opsi b: label "Pendapatan" & sub keluar dari bidang oranye, atau
   dinaikkan ke ukuran/bobot teks besar. Opsi c: tandai pengecualian resmi di DNA (tanpa ubah kode).
2. **#2** — empty state terdesain per kartu ("Belum ada order masuk" + aksi), dan banner error bila
   API gagal (jangan diam-diam menyuguhkan seed).
3. **#3** — padatkan kartu "Komposisi order" (donut kiri + legenda satu-baris kanan) seperti opsi audit 011.
4. **#4** — kunci sistem radius: badge/dot/track pakai token yang benar (bukan `9999px` serampangan);
   sisakan pill hanya untuk avatar & segmented.
5. **#6** — samakan jarak antar blok ke satu langkah (`--space-4` atau `--space-5`) untuk ritme RHYTHM 1.
