## A. Diperbaiki di sesi ini

### HG-01 · Kepala foto Masuk & Daftar hilang (7 bingkai, regresi)

`Body` (isi #F4F4F6, 390x844, y=0) dicat **di atas** `Hero foto` (y=0, 240) di bingkai 275, 302, 331, 358, 740, 775, 818. Foto tidak pernah terlihat; tile merek y=-40 jadi terpotong tepi atas bingkai.

Bukti piksel sebelum: `file.export 275` = 37.687 B, piksel (200,120) = `#F4F4F6` (polos, tanpa foto). Sesudah `Body y=240 h=604`: ekspor 182.323 B, piksel (200,30) = (87,120,152) dan (200,120) = (100,128,139) (foto), (200,300) = `#F4F4F6` (panel).

Sumber benar: `docs/design/slice/beta/beta.css:179` `.hero { height: 240px }` + `:235` `.body { flex: 1 }` (604) + `:247` `.brandmark { margin: -40px auto 0 }`.

Perbaikan: `Body` absolute `y=240, h=604`, constraint `leftRight/topBottom`; `Action bar` `y=520` constraint `bottom`; tombol `y=536` constraint `bottom`.

### HG-02 · Baris Consent meluber (bingkai 903)

`Consent` 350x44 memuat dua layer teks 248x40 (82 total) → layer teks keluar 19 px dari atas induk (y=-19, h=82, induk 44). Dua paragraf ditumpuk padahal HTML satu paragraf ber-`<strong>` inline (`docs/design/slice/beta/auth/tambah-peran.html:116`).

Perbaikan: `Consent` tinggi 82, diletakkan `y=670` (jarak 22 px ke tombol di 776). Sesudah: 0 layer keluar kotak.

### HG-03 · Tiga panah kembali hanya bisa diklik 18x18

`Pilih peran / 3` (700/701), `Tambah peran / 1` (867/868), `Tambah peran / 2` (906/907): interaksi `back` menempel di vektor 18x18 di dalam lingkaran 44x44, jadi klik di ring tidak melakukan apa pun.

Perbaikan: aksi `back` dipindah ke induk 44x44, dihapus dari vektor anak (kalau keduanya aktif satu klik = dua kali back).

### HG-04 · Dua hotspot di bawah 44 px

`Ubah nomor` (1866, bingkai 1586) 145x21 → 145x44. `Link Ganti nomor` (584, bingkai 567) 350x40 → 350x44. Sesudah: 0 hotspot < 44 px dari 78 interaksi.

## B. Temuan terbuka (belum diubah)

### PG-01 · Teks abu terang 2,56:1 (Verifikasi merchant 959/979/999)

`#94A3B8` di atas `#FFFFFF` = **2,56:1**, 13 px Medium. Muncul di "Menunggu persetujuan" (2271) dan "Setelah diperbaiki" (2325). Batas AA teks normal 4,5:1. Ganti `#64748B` (4,76) atau `#475569` (6,90).

### PG-02 · Tab aktif "Masuk" 3,75:1

`#E44220` di atas `#F4F4F6` = **3,75:1** pada 15 px SemiBold (label tab, 4 bingkai Masuk). `--orange-ink #B83213` = 5,46:1 untuk peran yang sama.

### PG-03 · Baris bantu 4,33:1

`#64748B` di atas `#F4F4F6` = **4,33:1** pada 13 px Medium ("Untuk pembeli, warung, dan kurir. Satu nomor, satu akun.", 4 bingkai). `#475569` = 6,90:1.

### PG-04 · Delapan bingkai tanpa jalan masuk dan tanpa kembali

Tanpa `navigate` masuk DAN tanpa aksi `back`: 302, 358, 567, 588, 660, 979, 999, 1368. Bisa dibuka hanya lewat daftar bingkai, tidak lewat prototipe. 660 (satu peran) dan 1368 (inbox kosong) adalah keadaan produk yang wajar, jadi paling terasa: keduanya tidak bisa dicapai sama sekali. Pilihan: tautkan dari layar sebelumnya (butuh keputusan pemilik) atau biarkan sebagai bingkai referensi.

### QL-01 · Tile merek memakai oranye v1

27 isian `#E8441C` pada layer `Brand` vs token merek `#E44220` (`src/styles/_tokens.scss:8`). Selisih tipis, tapi satu merek dua nilai.

### QL-02 · Tiga warna satu pemakaian di luar token

- `#FCFCFD` — panel "Detail peran" (bingkai 1696), seharusnya `--surface #FFFFFF`.
- `#FFF7E6` — Avatar (bingkai 697), seharusnya `--orange-soft #FFF0EB`.
- `#BBE5D3` — garis penghubung 2x95 (bingkai 959), tidak ada di token; `--success-soft #ECFDF5` atau `#047857` untuk garis.

### QL-03 · Radius di luar skala

Skala token 8/10/12/16/24/32/pill. Terpakai juga 4 (6x), 6 (5x), 20 (7x). 3 dipakai `Home indicator` (134x5, sah). 28 untuk kepala navy dan 32 untuk `Hero foto` auth: sengaja beda, auth mengikuti acuan pemilik `login-1to1.html`.

### QL-04 · Nomor langkah nonaktif 2,25:1

Lingkaran "3" `#94A3B8` di atas `#EFF0F2` = 2,25:1 (butuh 3:1 untuk elemen non-teks). Statusnya memang nonaktif; kalau dipertahankan, catat sebagai pengecualian, kalau tidak naikkan ke `#64748B`.

### QL-05 · Consent dua paragraf, bukan satu

Perbaikan HG-02 menyelamatkan luberan, tetapi bentuknya masih beda dari HTML: dua layer teks bertumpuk (masing-masing membungkus 2 baris, 82 px) vs satu paragraf dengan `<strong>` inline (~50 px di 350 lebar). FigCraft tidak punya rich text inline, jadi ini batas alat; catat di README supaya port React memakai satu paragraf.
