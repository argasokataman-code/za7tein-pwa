Perbaikan: scroll document-only untuk home/search/filter, alamat, kartu, ulasan, dan form autentikasi; fixed auth screen, banner PWA, dokumentasi, modal, dan toast dibatasi shell. Navigasi home dan 17 panah kembali memakai Lucide 1.75. Palet lokal dokumentasi sekarang mengacu pada token global.

Audit kode lanjutan: 5 SVG inline di 4 file TSX (turun dari 135 di 41 file awal). Kelimanya dekorasi atau identitas merek; seluruh ikon fungsional sudah memakai Lucide. `legacy-debt.json` sekarang mengunci pengecualian SVG tersebut dan membatasi warna mentah menjadi 54 kemunculan di 12 file lapisan UI, termasuk komentar, logo, dan nilai alpha untuk compositing. Placeholder toast palsu di 35 layar dihapus; toast global di `App.tsx` tetap berfungsi. Tombol tampilkan sandi pada SignIn, SignUp, dan ChangePassword sekarang kontrol keyboard dengan target 44px.

Audit browser diulang setelah migrasi ikon: **55/55 rute** lulus pada lebar 390px dan **55/55 rute** pada 1440px untuk lebar shell (390/430px), overflow horizontal (0), penggulung vertikal bersarang (0; elemen `html` sebagai penggulung dokumen dikecualikan), dan elemen fixed yang melewati 430px (0).

Yang belum dibuktikan oleh audit ini: semua state interaksi, target sentuh seluruh rute, fokus keyboard seluruh rute, kontras komposit seluruh rute, dan kesesuaian copy/aturan bisnis dengan PRD Irbid aktif.
