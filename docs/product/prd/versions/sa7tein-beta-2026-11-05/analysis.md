### Batasan & risiko diterima (§21)

- **L1** lokasi kurir andal hanya saat app kurir terbuka & layar menyala (PWA). **L2** iOS web push hanya bila PWA di-install.
- Risiko material: **R1** payment gateway belum dipilih (blocker uang) · **R2** legal belum dipetakan · **R3** registry DO eventually consistent (≤60 dtk) · **R4** biaya Routes API (auto-sort tanpa debounce + fee radius) · **R6** payout otomatis setelah selesai + dana dicairkan · **R7** kuota bisa terlampaui bila konsumsi saat selesai (dimigasi: reserve saat order dibuat) · **R8** update kurs gagal · **R9** tracking PWA kurang andal · **R10** gift card/eWallet stored value (dihapus) · **R12** nomor WA diblokir/gangguan Cloud API · **R13** payout/refund menunggu pencairan QRIS 1–2 hari kerja · **R14** ledakan jumlah instance DO karena riwayat per field.
